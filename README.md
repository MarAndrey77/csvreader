# CSV Formula Reader

## Описание

Программа читает CSV-файл с таблицей, вычисляет значения ячеек с формулами и выводит результат в формате CSV в консоль.

Имя CSV-файла передаётся первым аргументом командной строки.

Компилятор gcc

Пример запуска:

```bash
./csvreader source/data.csv
```

## Формат ячеек

В ячейке может быть:

1. Целое число:

```text
123
-45
0
```

2. Формула вида:

```text
=ARG1OPARG2
```

где:

- `ARG1` и `ARG2` — целые числа или адреса ячеек;
- `OP` — одна из операций: `+`, `-`, `*`, `/`.

Пробелы внутри формулы поддерживаются за исключением пробелов в названиях столбцов.

## Формат адреса ячейки

Адрес ячейки записывается в формате:

```text
ColumnNameRowNumber
```

Примеры:

```text
A1
B2
Cell30
Alpha100
```

## Требования к таблице

- номера строк — целые положительные числа;
- номер строки должен быть меньше `10_000_000`;
- названия столбцов не должны повторяться;
- номера строк не должны повторяться;
- пробелы в названиях столбцов недопустимы;
- содержимое одной ячейки должно быть не более 256 символов;
- количество значений в строке должно соответствовать количеству столбцов;
- ссылки в формулах должны указывать на существующие ячейки;
- деление на ноль считается ошибкой;
- циклические зависимости между формулами считаются ошибкой.

## Пример

Входной файл:

```csv
,A,B,Cell
1,1,0,1
2,2,=A1+Cell30,0
30,0,=B1+A1,5
```

Вывод программы:

```csv
,A,B,Cell
1,1,0,1
2,2,6,0
30,0,1,5
```
### 1. Скачивание

```bash
git clone https://github.com/MarAndrey77/csvreader.git
cd csvreader
```
## Сборка

Сборка выполняется через `make`.

```bash
make 
```
или
```bash
make compile
```
После сборки создаётся исполняемый файл:

```text
csvreader
```

## Запуск

Запуск с файлом по умолчанию:

```bash
make run
```

Запуск с указанным CSV-файлом:

```bash
make run SOURCE=source/data.csv
```

Запуск напрямую:

```bash
./csvreader source/data.csv
```

## Тестирование

Запуск всех тестов:

```bash
make test
```

Тесты находятся в папке `tests`:

```text
tests/valid
tests/invalid
```

- `tests/valid` содержит корректные CSV-файлы;
- `tests/invalid` содержит некорректные CSV-файлы.

Для каждого теста есть файл с ожидаемым выводом:

```text
test_name.csv
test_name.out
```

При запуске тестов программа сравнивает фактический вывод с ожидаемым с помощью `diff`.

## Очистка

```bash
make clean
```
